1. Computer Hardware and Software
There are two fundamental parts of any computer system; hardware and software.

💾 Hardware
Hardware refers to the physical components of a computer —parts you can see and touch such as:
•  Keyboard, mouse, and monitor
•  CPU (Central Processing Unit)
•  Motherboard, graphic cards, and power supply, and memory devices like RAM and hard drives.

‍💻 Software
Software refers to the programs that tell the hardware what to do. It is not physical, but controls hardware
such as:
•  Operating systems like Windows, Mac.
•  Applications like Microsoft Word, Google Chrome, and games.

So, hardware acts as the body, while software acts as the brain of computer.

2.1 Input Units
Input Units: Bringing Data Into the System; allow user to interact with computer by external data or inserting commands.
•  Examples:
      o   Keyboard: For entering text, commands, and data.
      o   Mouse: Enables pointing, clicking, and dragging in graphical user interfaces.
      o   Scanner: Converts physical documents into digital format.
      o   Microphone: Captures audio input, used in voice recognition or sound recording.
      o   Webcam: Captures video for video calls, recordings, or surveillance.

2.2 Output Units
Output Units: Displaying the Results; allow computer to show or present the processed data to user.
• Examples:
      o   Monitor: Displays visual output, such as text, images, or videos.
      o   Printer: Converts digital documents into physical printouts.
      o   Speaker: Outputs sound or audio.

2.4 Storage Units
Storage Units: Saving Data temporary or permanent.
•  Primary Storage:
    o  ROM (Read-Only Memory): )‫(ذاكرة للقراءة فقط‬
             - Stores firmware )‫( (البيانات التعريفية الثابتة للجهاز‬boot instructions) required to start the system.
             - ROM can’t be modified.

     o   RAM (Random Access Memory): )‫(ذاكرة الوصول العشوائى‬
             - Provides fast storage for data at operation.
             - Temporary as data is lost when computer is turned off.
             - Its size define computer speed at operation.

•   Secondary Storage (Permanent):
     o Hard Drive: Used for long-term storage of large amounts of data. Slower than RAM.
     o USB Flash Drive: Universal Serial Bus (USB) portable storage with easy data transfer.
     o CD/DVD: Compact Disc (CD) & Digital Video Disc (DVD) commonly used for multimedia or software.

2.4 Storage Units
    Data size units (prefixes) that are commonly used:
    Byte (B), Kilobyte (KB), Megabyte (MB), Gigabyte (GB), and Terabyte (TB)

                   1 Byte = 8 Bits (Bit is 0 or 1)

•    1 Byte = Basic unit = 2^0          → letter

•    1 KB = 1,024 B      = 2^10 bytes → short text file

•    1 MB = 1,024 KB = 2^20 bytes → image or small audio

•    1 GB = 1,024 MB = 2^30 bytes → video

•    1 TB = 1,024 GB = 2^40 bytes → large hard drive

2.5 Peripheral Units (Cards)
Peripheral Cards help in translating computer information into forms humans can understand.

Cards may be built-in motherboard or external devices.

Common types are:

•    Graphics card → Converts computer data into images/videos for the monitor.

•    Sound card → Converts computer data into sounds for speakers (and vice versa for microphones).

•    Network card → Internet and networking
