Introduction
Computer software is the collection of programs that tell the hardware how to operate.
In simple terms, if hardware is the body of a computer, then software is its mind.

Software can be divided into two categories:
1. System Software:
     Programs that provide platform for applications to run as Operating Systems and device drivers.
     o   Example: Microsoft Windows, Linux, macOS.

2. Application Software:
     Programs designed to help users perform specific tasks.
     o   Example: Microsoft Word, Excel, PowerPoint, web browsers.

What is Microsoft Windows?
Microsoft Windows is a graphical operating system developed by Microsoft.
It started in 1985 as an add-on to MS-DOS and has evolved into a user-friendly platform.

Key Features of Windows:
       Graphical User Interface (GUI): Point-and-click with mouse or touch.
       Multi-tasking: Run multiple apps at once.
       Security: Built-in antivirus (Windows Defender) and updates.

Brief History:
       1985: Windows 1.0 – GUI Basic windows and mouse support.
       1995: Windows 95 – Introduced Internet Explorer.
       2001: Windows XP – Stable and user-friendly.
       2009: Windows 7 – Improved performance.
       2015: Windows 10 – More advancement.
       2021: Windows 11 – Modern design with AI features.

1. Starting Microsoft Word
Microsoft Word is a word processing software developed by Microsoft. It is part of the Microsoft Office
suite of programs and is used for creating, editing, formatting, and printing text documents.


To open Microsoft Word:
Click on the Start menu at the bottom left of your screen (Windows icon).
Type Word in the search bar, then click on Microsoft Word when it appears.
When Microsoft Word opens, you will be presented with a blank document or several templates you can
choose from.




  15
2. Word Interface
Once the program is open, you will see the following main components:
1. Writing Area: This is the large white area where you can type and edit your document.
2. Ribbon: The ribbon is at the top of the screen and contains different tabs such as Home,
  Insert, Design, Layout, etc. Each tab contains tools for different tasks.
3. Quick Access Toolbar: Located above the ribbon, this toolbar allows quick access to
  common tools (e.g., Save, Undo, Redo).
4. Status Bar: Found at the bottom of the window, it shows information about your
  document such as page number, word count, and language.

3. Creating and Saving a Document
Creating a New Document:
      o   When you first open Word, you’ll see a blank page. Start typing to create content.
      o   You can also create a new document by clicking File > New > Blank Document.
Saving Your Document:
      o   Click on File in the top-left corner.
      o   Select Save As to save the document for the first time.
      o   Select Word Document (*.docx) as the file type.
      o   Choose the location (e.g., Desktop or Documents) and name your document.
      o   Click Save.
      o   To save your work after changes, simply click Ctrl + S.

      Tip: Save frequently to avoid data loss using (Ctrl + S).

4. Typing and Editing Text
    Click in the document area and start typing.

    To edit text, click where you want to make changes, or use the arrow keys to navigate.


    Use Backspace to delete characters to the left or Delete to remove characters to the right.

    o   Highlight the text you want to format.
    o   On the Home tab, under the Font group, you can change the font style, size, and color.
    o   Select a new font style (e.g., Arial, Times New Roman), and increase or decrease the font size.

7. Inserting and Formatting Images
Inserting an Image:
      • Place the cursor where you want the image.
      • Go to Insert > Pictures > This Device, select an image file, and click Insert.
Resizing and Positioning the Image:
      •Resize the image by dragging its corners.
Picture Format:
      • Use Picture Format tab to add effects like borders or shadows.
Text Wrapping Around the Image:
      • Select the image, then click on Wrap Text (found under the Picture Tools > Format tab).
      • Choose a wrapping style like Square, Tight, or Through to control how text flows around the image.



 25
8. Tables
Inserting a Table:
      o   Place the cursor where you want the table.
      o   Go to the Insert tab.
      o   Click on Table, and a grid will appear. Select the number of rows and columns you want for your
          table.
      o   After inserting the table, you can enter text into the cells.
Formatting the Table:
      o   To format the table, click anywhere inside the table.
      o   A new tab called Table Design will appear. You can change the table style, apply shading, and more.




 26
9. Headers, Footers, and Page Numbers
Adding a Header:
    o   Click on the Insert tab.
    o   Click Header, then choose a style. A header section will appear at the top of your document.
Adding a Footer:
    o   Click on the Insert tab.
    o   Click Footer, and choose a style. A footer section will appear at the bottom of your document.
Adding Page Numbers:
    o   Click on the Insert tab.
    o   Click Page Number, and select where you want the page number to appear (top, bottom, or margin).

10. Proofreading
Grammar Check:
       o   If there is a grammar issue, Word will underline the error with a blue line. Right-click on the
           underlined word to view suggestions.
Spell Check:
       o   Word automatically checks spelling as you type and highlights errors with a red underline.
       o   Right-click on the underlined word and choose the correct spelling or suggestion.
Synonyms (‫ )المرادفات‬:
       o   Right-click on a word and choose Synonyms to find alternative words using the Thesaurus.
